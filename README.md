# 🌱 Углеродные единицы — веб-сервис

Спутниковая верификация «зелёных» инвестиций и углеродных кредитов.

## Что делает

Веб-сервис для оценки запасов углерода в лесной территории и анализа их изменений по спутниковым данным **ESA CCI Biomass**, **Sentinel-2**, **Hansen GFC** и **MODIS**.

## Возможности

- 🗺️ Интерактивная карта 4 участков (Тверь, Вологда, Мордовия 03/04)
- 📊 Расчёт углеродных единиц по методологии МГЭИК 2006
- 💰 Оценка стоимости по сценарным ценам (500 / 1500 / 4000 ₽)
- 🔥 Данные о пожарах 2021 года
- 📈 Графики динамики запаса углерода
- 🎯 Три стратегии для инвестора: **Покупать / Держать / Создать ферму**

## Стек

- **Backend:** Node.js, Express, better-sqlite3
- **Frontend:** HTML, CSS, JavaScript, Leaflet, Chart.js
- **Данные:** ESA CCI Biomass v7.0, Sentinel-2 L2A, Hansen GFC 2025 v1.13, MODIS MCD64A1 v6.1

## Запуск

```bash
# 1. Установить зависимости
npm install

# 2. Инициализировать базу данных
npm run init-db

# 3. Запустить сервер
npm start

# 4. Открыть в браузере
# http://localhost:3000
Методология
Учитываемый пул: надземная древесная биомасса (AGB)

Коэффициент: CF = 0,47 т С / т сухого вещества (МГЭИК 2006, том 4, гл. 4, табл. 4.3)

Метод: разность запасов (stock-difference)

Перевод в CO₂: 44/12

Базовая линия: сценарная, из baseline.csv

Неопределённость: вычет UNC, резерв BUF = 15%
